1. Overview and Architecture

The Hack computer is a 16-bit Von Neumann architecture comprised of an ALU, two registers (A and D), a Program Counter (PC), 32K instruction memory (ROM32K), and 32K unified data memory (Memory) addressing 16K RAM, 8K Screen memory-mapped display, and the keyboard register.

2. Part A – Build and Test the Computer

All hardware chips were implemented in Hack HDL according to specification:

  • CPU.hdl: Implements complete instruction decode for A-instructions and C-instructions, ALU operation routing, destination writing (A, D, M), and jump condition branching logic (combining zr and ng flags).
  • Memory.hdl: Uses DMux4Way and Mux4Way16 driven by address[13..14] to cleanly map the 16K RAM (0–16383), 8K Screen (16384–24575), and Keyboard (24576).
  • Computer.hdl: Glues together the CPU, Memory, and ROM32K in a closed loop.

3. Part B – Python Assembler (assembler.py)

A two-pass assembler in Python was developed:

  • Pass 1: Cleans comments (//...) and blank lines; records label definitions (LABEL) with their corresponding ROM instruction index. Detects duplicate labels for K mod 3 = 2.
  • Pass 2: Translates A-instructions (allocating user variables at RAM[16] upwards) and C-instructions (encoding comp, dest, and jump tables into 16-bit binary). Handles line-number error reporting for K mod 3 = 1 and saves symbols.txt for K mod 3 = 0.

4. Part C – Box Program (Box.asm)

The program polls RAM[24576] (KBD). When a key is held down, it paints a black rectangle starting at Row 41 (RAM address 17696), 20 rows tall and 32 pixels wide (2 consecutive words per row). When released, it clears the area back to white.

5. One Mistake I Fixed

Encountered Mistake:
While writing the row increment loop in Box.asm, I wrote M=M+D to advance the row address: 
Line 93: invalid instruction: M=M+D
Assembly failed with errors.
Cause: In the Hack ALU grammar, additions are mnemonically specified as D+M (or D+A). Although addition is mathematically commutative, standard Hack instruction sets mandate having register D as the first operand.

Fix: I updated Box.asm to M=D+M, and enhanced assembler.py to support commutative aliases (such as M+D, A+D, M&D) while maintaining strict adherence to the Hack ISA specification.

6. Viva Voce Preparation

How to handle on-the-spot code modifications:
  • Move the box down: Update the base address @17696. To shift down by 10 rows, add 32 * 10 = 320 → change to @18016.
  • Change width: Change @col_count initialization (e.g. from @2 to @3 for 48px).
  • Change height: Change @row_count initialization (e.g. from @20 to @30).
